Las flechas, rótulos y diagramas explican ideas; no son parte del arte final. La lámina Idle tiene ocho poses, pero mide 1774 × 887 px: debe redibujarse o prepararse con ocho celdas exactas de 256 × 256 px antes de usarse como sprite sheet de Unity. La [ficha de Alma](../Docs/Player/Alma.md) define sus mecánicas y animaciones. El inventario define el nombre y la función de cada futuro prefab.
